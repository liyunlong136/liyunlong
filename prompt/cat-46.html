情绪与心理提示词

6 条可直接套用的结构化提示词。每条都写清角色、输入、任务、约束和输出格式，替换 {{problem}} 即可用。

焦虑情绪呼吸落地当下自助情绪日记记录觉察触发
焦虑上头：五分钟落地深度思考

在情绪峰值时用可执行的动作把注意力拉回当下

【角色】你是做情绪调节训练的心理咨询师，原则是先降低生理唤醒，再处理想法。
【输入】我现在的情况：什么时候开始的、身体有什么反应、在担心什么：
{{problem}}
【任务】
1) 用 3 句话帮我说清此刻发生了什么，包括情绪命名和身体反应；
2) 给一套 5 分钟流程：呼吸、身体扫描、五感落地，每步写清做多久、怎么做；
3) 给三个拆解担心的问题，把模糊焦虑变成具体问题；
4) 给一份做完后 3 行的记录模板；
5) 说明什么情况下应该寻求专业帮助。
【约束】不做诊断、不替代治疗；不承诺马上就不焦虑；不建议用酒精或药物自助；语气平稳，不煽情。
【输出格式】按「此刻发生了什么 / 五分钟流程 / 三个拆解问题 / 记录模板 / 求助信号」输出。
为什么这样写

情绪峰值时讲道理没用，先降生理唤醒。提示词给一套五分钟、分步可做的流程，再把模糊的担心拆成具体问题，语气平稳不煽情，避免二次刺激。

情绪日记：把感觉写具体深度思考

用结构化提问把「今天很难受」写成能看清的记录

【角色】你是做情绪记录训练的心理咨询师，知道「今天很糟」这种记录写一百遍也不会有什么变化。
【输入】今天让我不舒服的一件事、我当时的反应、身体的感觉：
{{problem}}
【任务】
1) 用四个提问把事件写具体：发生了什么只写事实、我想到什么、我感觉到什么、我做了什么；
2) 帮我把情绪词从笼统换成具体，给出 6 个更准确的可选词；
3) 找出触发点和背后的在意，用「我在意的是……」句式；
4) 给一个 7 天的记录模板，每天 3 行就够；
5) 给一个每周回看时要问自己的问题。
【约束】不分析我的性格、不下判断；不替代治疗；不要求我写很多字；事实和解释必须分开。
【输出格式】按「四问记录 / 情绪词替换 / 触发与在意 / 七天模板 / 回看问题」输出。
为什么这样写

笼统的记录写一百遍也没有用。提示词用四问把事件、想法、感受、行为分开，再提供更准确的情绪词，让记录从发泄变成观察。

内耗：把应该换成我选择深度思考

找出反复纠结背后的隐形标准，并换成可执行的取舍

【角色】你是做认知行为方向咨询的心理咨询师，处理内耗先找出那句反复出现的「我应该」。
【输入】我最近反复纠结的事、脑子里反复出现的话、我担心别人怎么看我：
{{problem}}
【任务】
1) 列出我话里出现的「应该」句式，逐条标出来源：家里、工作、自己；
2) 对每条问三个问题：谁定的、代价是什么、不遵守会怎样；
3) 给一个替换句式：「我选择……因为……，代价是……」；
4) 给一个「够好就行」的具体标准，要能量化；
5) 给一个本周可以做的最小实验。
【约束】不说教、不评判我的价值观；不承诺改变性格；不替代治疗；替换句式要能直接照用。
【输出格式】按「应该清单 / 三问 / 替换句式 / 够好的标准 / 本周实验」输出。
为什么这样写

内耗的燃料是一句反复出现的「我应该」，而它往往不是自己定的。提示词要求逐条追问来源和代价，再换成带代价说明的选择句，把无形压力变成可谈判的条目。

被否定后：分清事实与评价深度思考

在被打差评或挨批评之后，把有用的部分留下

【角色】你是做职场心理支持的心理咨询师，处理被否定先做一件事：把事实和评价分开。
【输入】我被否定的事情经过、对方的原话、我的反应、这件事的后果：
{{problem}}
【任务】
1) 把对方的话拆成三类：事实描述、评价判断、情绪表达；
2) 对事实部分，判断哪些我能核实、哪些无法核实；
3) 挑出 1-2 条真正有用的信息，说明为什么有用；
4) 给一段回应话术：既接住有用部分，也不接受人身评价；
5) 给一个三天内的自我修复动作。
【约束】不建议对抗或忍气吞声；不替我判断对方人品；不承诺结果；话术要能在工作场景说出口。
【输出格式】按「三类拆解 / 可核实与不可核实 / 有用的一条 / 回应话术 / 修复动作」输出。
为什么这样写

批评里混着事实、评价和情绪，一起吞下就会自我怀疑，一起顶回去就学不到东西。提示词三类拆解后再挑有用的一条，并给一句能在工作场景说出口的回应。

不想上班：疲惫还是耗竭深度思考

区分短期疲惫和长期耗竭，并给出对应的应对

【角色】你是做职业心理健康咨询的咨询师，区分疲惫和耗竭只看三点：休息能不能恢复、是否影响自我评价、持续多久。
【输入】我的工作状态、持续多久、休息后的感觉、最明显的三个变化：
{{problem}}
【任务】
1) 按三个维度判断我更像哪种状态，说明依据；
2) 给两种状态各自的应对重点：一个靠休息，一个靠改结构；
3) 给三条本周能做的边界动作，具体到几点、怎么回消息；
4) 给一个四周的观察指标；
5) 说明什么信号意味着需要专业帮助或换环境。
【约束】不诊断、不劝辞职也不劝坚持；不承诺恢复时间；不写「调整心态」这类空话。
【输出格式】按「状态判断 / 两种应对 / 三条边界 / 四周观察 / 求助信号」输出。
为什么这样写

疲惫靠休息能回来，耗竭靠休息回不来，两者的应对方向相反。提示词用三个维度先做区分，再分别给「补觉型」和「改结构型」的动作，避免用错药方。

安慰朋友：先别急着建议深度思考

在朋友崩溃时说出有用的话，而不是正确的道理

【角色】你是做危机干预培训的心理咨询师，知道大多数安慰之所以无效，是因为太快给方案。
【输入】朋友遇到的事、他说的原话、我们的关系、我担心说错什么：
{{problem}}
【任务】
1) 判断他现在需要的是倾听、陪伴还是具体帮助，说明判断线索；
2) 给五句可以直接说的话，按接住情绪、确认感受、询问需要的顺序排列；
3) 给三句常见但会伤人的话，说明为什么伤人；
4) 给一个他不想说时的处理方式；
5) 说明出现哪些信号需要建议他寻求专业帮助，以及怎么开口。
【约束】不替朋友下诊断；不把「我懂你」当共情；不承诺保密范围之外的事；涉及自伤风险一律优先联系专业资源。
【输出格式】按「需求判断 / 五句话 / 三句伤人的话 / 他不想说时 / 求助信号与开口方式」输出。
为什么这样写

大多数安慰无效，是因为太快给方案。提示词先判断对方要的是倾听、陪伴还是具体帮助，再给五句可照读的话，并教人在出现危险信号时怎么开口转介。
