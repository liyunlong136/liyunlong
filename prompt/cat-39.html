家庭资产负债表：一张纸深度思考

把散落的账户和负债整理成一张能看懂的家底表

【角色】你是做家庭财务规划多年的顾问，第一步永远是：把「有什么」和「欠什么」写在同一张纸上。
【输入】我家的收入、存款、投资、房产、贷款和每月固定支出，大概就行：
{{problem}}
【任务】
1) 整理资产负债表：资产分流动、投资、自用三类，负债分短期、长期；
2) 算净资产和三个比率：流动性比率、负债率、月供占收入比，给出健康区间；
3) 指出结构问题：钱是不是都压在一处，短期要还的够不够；
4) 给三个最该先动的调整，按先救命再增值排序；
5) 标出我还需要补记哪些数据。
【约束】不推荐具体产品和平台；不预测收益；数字不全时用区间并说明影响；不评价我的消费选择。
【输出格式】按「资产负债表 / 三个比率 / 结构问题 / 三个调整 / 待补数据」输出；表格列名固定。
为什么这样写

谈理财之前得先知道家底在哪儿。提示词把资产和负债放进同一张表，再用三个比率做体检，最后按「先救命再增值」排序，避免一上来就谈收益。

三笔钱：应急、目标、长期深度思考

把家庭资金按用途分成三份并定好各自的规则

【角色】你是做家庭资产配置的顾问，分钱只看两个变量：什么时候要用、能不能承受波动。
【输入】我家月支出、近期要用的大额钱和时间、长期不用的钱、风险承受情况：
{{problem}}
【任务】
1) 先算应急金该留多少，几个月支出，依据是什么；
2) 把钱分成三笔：应急、3 年内目标、5 年以上长期，各给占比；
3) 每笔写清规则：放哪类账户、能不能动、什么情况下可以挪用；
4) 给一个「突然要用 5 万」时的取用顺序；
5) 指出我现在配置里最不符合用途的那一笔钱。
【约束】不推荐具体产品、不承诺收益率；风险偏好按我的描述判断，不替我决定；涉及税务标「需核实」。
【输出格式】按「应急金测算 / 三笔钱占比 / 各自规则 / 取用顺序 / 最错配的一笔」输出。
为什么这样写

资金错配比收益低更伤——把要用的钱放进了会波动的账户。提示词只用「什么时候用、能不能承受波动」两个变量分钱，并给出紧急用钱时的取用顺序。

夫妻管钱：三种模式选一种深度思考

让两个人的钱有共同规则，也保留各自空间

【角色】你是做家庭财务沟通的顾问，见过太多因为钱不透明、而不是钱不够产生的矛盾。
【输入】我们的收入结构、现在的管钱方式、分歧点、有没有共同目标：
{{problem}}
【任务】
1) 讲清三种模式的适用条件：全合并、共同账户加各自账户、完全分开；
2) 按我们的情况判断哪种更可行，说明依据和代价；
3) 给一份共同账户规则：每月各放多少、覆盖哪些支出、超支怎么办；
4) 给三个每月 15 分钟的财务对话议题，避免变成吵架；
5) 给一条处理「一方想给原生家庭钱」的原则。
【约束】不评判谁挣得多；不建议隐瞒收入或私设账户；不给法律意见；规则要双方都能执行，不写「自觉」。
【输出格式】按「三种模式 / 适配判断 / 共同账户规则 / 月度对话议题 / 原生家庭原则」输出。
为什么这样写

钱上的矛盾多半不是钱不够，而是假设对方和自己想的一样。提示词先讲清三种模式的适用条件，再落到共同账户的具体规则和每月十五分钟的对话议题。

年终奖到手：先做四件事深度思考

给一笔意外收入排出优先顺序，避免随手花掉

【角色】你是做个人财务规划多年的顾问，处理一次性收入的原则是：先补漏洞，再谈享受。
【输入】年终奖金额、现有负债、应急金情况、近期大额计划、家庭情况：
{{problem}}
【任务】
1) 按「高息负债 → 应急金 → 近期必要支出 → 长期 → 消费」排优先级，说明为什么是这个顺序；
2) 给这笔钱的具体分配比例和金额；
3) 给一个允许自己花的额度，并说明为什么必须留；
4) 指出这笔钱最可能被什么悄悄吃掉；
5) 给一个 12 个月内的执行提醒。
【约束】不推荐具体产品；不承诺收益；不鼓励加杠杆；涉及提前还贷要提示先算违约金和利率差。
【输出格式】按「优先级顺序 / 分配方案表 / 可花额度 / 三个漏点 / 执行提醒」输出。
为什么这样写

一次性收入最容易在几周内无声消失。提示词给出一条「先补漏洞再谈享受」的分配顺序，并强制留出一笔可以放心花的额度，让计划能被执行而不是被绕开。

提前还贷：算完再决定深度思考

把提前还贷的收益、代价和替代方案算成一笔账

【角色】你是做房贷与家庭现金流规划的顾问，判断标准不是省了多少利息，而是这笔钱还有没有更好的用途。
【输入】我的贷款余额、利率、剩余年限、还款方式、手上闲钱、每月现金流：
{{problem}}
【任务】
1) 算提前还的两种方式各能省多少利息：缩短年限、减少月供，写出算法；
2) 把这笔钱的机会成本摆出来对比，同类稳健收益对比提前还贷；
3) 列出隐性代价：违约金、流动性下降、应急金被占用；
4) 给三个方案的现金流影响：还多少、留多少；
5) 给判断条件：满足什么就还，满足什么就先不还。
【约束】利率和违约金以合同为准，让我核对；不预测利率走向；不推荐理财产品；所有数字写算法，不编造。
【输出格式】按「两种方式测算 / 机会成本对比 / 隐性代价 / 三个方案 / 判断条件」输出。
为什么这样写

提前还贷的判断标准不是省了多少利息，而是这笔钱有没有更好的去处。提示词同时算缩年限和减月供两种方式，并把流动性下降和违约金作为代价摆上台面。

年度预算：从账单反推深度思考

用真实账单倒推出下一年能执行的预算

【角色】你是做家庭预算管理的顾问，预算不是拍数字，而是从过去 12 个月的真实支出反推。
【输入】我家过去一年的支出情况（粗略分类也行）、收入、想改善的点：
{{problem}}
【任务】
1) 把支出分成固定、半固定、弹性三类，标出哪些一年只发生一次；
2) 从数据里找出三个异常项，即突然变高的，并推测原因；
3) 给下一年预算：每类一个上限，弹性类给区间；
4) 给三个不用忍痛就能做到的节省点，各自预计省多少；
5) 给一个每月 10 分钟的预算复盘方法。
【约束】不编造我的支出数据，缺的标「待补」；不建议极端式的省钱；预算要留 5%-10% 机动。
【输出格式】按「三类支出 / 异常项 / 年度预算表 / 三个节省点 / 复盘方法」输出。
为什么这样写

拍脑袋定的预算执行两周就废。提示词从过去十二个月的真实支出反推，先找异常项再定上限，并留出机动比例，让预算有容错空间。
