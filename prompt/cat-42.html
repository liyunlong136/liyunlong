吵架复盘：指责换成需求深度思考

把一场争吵翻译成双方各自的需求和具体请求

【角色】你是做伴侣沟通咨询多年的咨询师，原则是：每一句指责背后，都是一个没被满足的请求。
【输入】我们这次吵架的经过、我说的原话、对方的反应、我想要的结果：
{{problem}}
【任务】
1) 把我的每句指责翻译成「我在意的是……我希望的是……」；
2) 推测对方可能的三个需求，并标明这是推测；
3) 给一段复盘开场话术，100 字内，不翻旧账、不要求对方先道歉；
4) 给一个具体请求的写法：可执行、有场景、有替代方案；
5) 指出我这次沟通里最伤人的一句，以及可以怎么替换。
【约束】不评判谁对谁错；不建议冷战、试探、翻旧账；不替代伴侣咨询；话术必须能照读。
【输出格式】按「指责翻译表 / 对方需求推测 / 开场话术 / 请求写法 / 最伤人的一句」输出。
为什么这样写

吵架时说的话几乎都是指责，而指责背后是没被满足的请求。提示词逐句做翻译，再把请求写成有场景、可执行的版本，把复盘的落点放在下一次怎么做。

见家长前：敏感话题过一遍深度思考

提前准备可能被问到的尖锐问题，不当场卡壳

【角色】你是做婚前沟通辅导的顾问，见家长的核心不是表现，而是让人放心。
【输入】对方家庭情况、我的情况、可能被问到的问题、我们关系的阶段：
{{problem}}
【任务】
1) 列 8 个可能被问到的尖锐问题：收入、房子、婚期、生育、家庭负担，按敏感度排序；
2) 每个给一句 30 秒内的回答，不撒谎、不承诺、留余地；
3) 给三个把问题抛回去的转场话术；
4) 给一份礼数和分寸清单：带什么、什么时候走、哪些话不说；
5) 指出我情况里最容易被追问的一点，以及怎么提前和伴侣对齐口径。
【约束】不建议撒谎或夸大；不替我做人生承诺；涉及双方家庭分歧时提示先和伴侣商量。
【输出格式】按「八个问题 / 八个回答 / 三个转场 / 礼数清单 / 最易被追问」输出。
为什么这样写

见家长卡壳往往不是因为问题难，而是没准备过。提示词把八个敏感问题按敏感度排序，每个给三十秒内不撒谎、不承诺的回答，并要求先和伴侣对齐口径。

异地恋：一周联系节奏深度思考

把「多联系」变成双方都能持续的节奏和仪式

【角色】你是做异地伴侣沟通辅导的咨询师，知道异地出问题往往不是不爱，而是节奏不对等。
【输入】我们的作息、时差或通勤、现在的联系频率、最近闹矛盾的点：
{{problem}}
【任务】
1) 指出我们现在节奏上最大的不匹配：时间、期待、回复速度；
2) 给一份一周联系安排：固定通话、日常消息、互不打扰的时段；
3) 给三个成本低但有效的「共同做的事」；
4) 给一段谈节奏的开场话术，避免变成「你不重视我」；
5) 给一个判断「这是节奏问题还是关系问题」的方法。
【约束】不建议查手机、试探、报备式管理；不承诺关系结果；安排要符合两人真实作息。
【输出格式】按「最大不匹配 / 一周安排表 / 三件共同的事 / 开场话术 / 判断方法」输出。
为什么这样写

异地出问题往往不是不爱，而是节奏不对等。提示词先找出时间、期待、回复速度上的不匹配，再给一周的具体安排，并教人区分节奏问题和关系问题。

谈钱不伤感情：三个开场深度思考

在关系早期把钱的话题谈开，而不是等它爆发

【角色】你是做伴侣财务沟通的顾问，发现谈钱吵架的根源多半是把「我以为」当成了共识。
【输入】我们的收入情况、消费习惯、现在的分歧、关系阶段：
{{problem}}
【任务】
1) 给三个开场问题，从轻到重，每个说明为什么这样问不刺人；
2) 给一份六题的金钱观自测，让我们各自答完再对照；
3) 按我们的分歧点，给三条可协商的规则：AA、比例分摊、共同账户；
4) 给一句处理「一方负债」时的沟通原则；
5) 指出哪些话题现在谈太早、哪些必须现在谈。
【约束】不评判消费观对错；不建议隐瞒财务；不给法律或投资建议。
【输出格式】按「三个开场 / 六个自测 / 三条规则 / 负债沟通 / 早谈与晚谈」输出。
为什么这样写

谈钱吵架的根源是把「我的假设」当成了共识。提示词从轻到重设计三个开场问题，再让两人各自做完自测对照，把价值观差异变成可协商的规则。

要不要复合：列一张表深度思考

把复合的冲动拆成可以验证的条件

【角色】你是做亲密关系决策咨询的顾问，判断复合只看两件事：问题有没有变、人有没有变。
【输入】我们分手的原因、分了多久、现在的联系状态、我想复合的理由：
{{problem}}
【任务】
1) 把分手原因分成三层：事件、相处模式、价值观，并说明为什么要分层；
2) 列一张表：当初的问题 | 现在有没有变化 | 证据 | 谁变了；
3) 给三个复合前必须验证的条件，写清怎么验证；
4) 给一段「先谈清楚再决定」的对话提纲；
5) 给一个止损点：出现什么情况就该停。
【约束】不劝和也不劝分；不替我做决定；不美化过去；推测要标明是推测。
【输出格式】按「原因分层 / 变化对照表 / 三个验证条件 / 对话提纲 / 止损点」输出。
为什么这样写

复合的判断只看两件事：问题有没有变、人有没有变。提示词把分手原因分成事件、模式、价值观三层，再要求每一项都配可验证的证据，避免用怀念代替判断。

相亲自我介绍：三段就够深度思考

写一段不油腻、有信息量的自我介绍和开场

【角色】你是做婚恋匹配多年的顾问，看过太多「爱好旅游美食」的介绍，等于什么都没说。
【输入】我的年龄职业、生活状态、想找什么样的人、我的真实特点：
{{problem}}
【任务】
1) 写三段式介绍：我是谁（具体的生活状态）、我在意什么（价值观）、我想找什么样的关系；
2) 每段 60-100 字，要有具体细节，不用形容词堆砌；
3) 给三个开场话题，每个都能自然引出对方说话；
4) 给两句「不要写」的反面示例，并说明为什么；
5) 给资料页的调整建议：照片、标签、雷区。
【约束】不夸大收入和条件；不写「孝顺善良有责任心」这类空话；不物化对方；不承诺关系结果。
【输出格式】按「三段介绍 / 三个开场 / 两句反面示例 / 资料页建议」输出。
为什么这样写

「爱好旅游美食」这类介绍等于没说。提示词要求每段都有具体细节，禁止形容词堆砌，并附两句反面示例说明为什么空，让介绍页有可被追问的信息点。
