使命

让更多人学会使用模型

我们不做「最强模型排行榜」，因为那解决不了大多数人的问题。真正的问题是：不知道这一步该用谁、不知道为什么、不知道要花多少钱、不知道该怎么开口。这个站点把四件事拆开讲清楚，并且永久免费。

为什么不是「直接用最强的那个」

同一个任务，用 L5 顶级模型和 L2 轻量模型的差距，往往远小于「提示词写得好不好」的差距。而成本可能差 30 倍。真正影响结果的，是任务有没有被拆对、约束有没有说清、输出格式有没有定死。

推荐逻辑

  • 先拆解：按领域把问题拆成 3-4 个有依赖关系的子任务，每个子任务单独匹配模型（同一个问题，第 1 步和第 3 步适合的模型经常不同）。
  • 再打分：每个子任务有权重向量（推理 / 代码 / 写作 / 中文 / 长文 / 多模态 / 速度 / 性价比 / 智能体 / 数学），与模型能力向量做加权匹配。
  • 加约束：硬需求（上下文、图片、音频、私有化）先做排除；再按预算、时间、token 余量做加减分，最终给出 0-100 的规则匹配分（不是成功率）。
  • 给理由：每条推荐必须说清「哪项能力匹配、这一步大约花多少钱、有什么坑」，而不是只给名字。
  • 三套路线：质量优先 / 省钱优先 / 速度优先，算好每条路线的单次成本，由你自己权衡。

等级怎么分

L1 免费或近免费；L2 轻量，适合分类、抽取、改写等高频率低难度任务；L3 主力，日常 80% 的任务；L4 旗舰，复杂工程、长文、难推理；L5 顶级，关键路径与高价值研究。等级不是「好坏」，是「用在哪一层」。

上传的文件怎么处理

  • 不上传：图片、PDF、Word、Excel、PPT、代码都在你的浏览器里解析，文件内容不会发到任何服务器，也不会被保存。
  • 只读概况：文本类会读取正文判断主题与篇幅；PDF 只提取可读文字；图片只读尺寸与色调，不做 OCR。
  • 按需筛选：图片或扫描件会自动按「需要视觉」过滤模型；长文档会自动抬高上下文门槛。
  • 你仍要上传：本站只负责推荐和写提示词。选定模型后，把原文件拖进它的对话框，提示词里已经写好了附件说明。
  • 扫描件建议：先转成清晰的图片或可复制文字的 PDF，再交给视觉模型；表格数字务必人工复核。

模式怎么选

  • 深度思考：数学、算法、架构设计、难 bug 再开。简单任务开了只会更慢更贵，还容易过度推理。
  • 非思考 / 快速：分类、抽取、改写、翻译这类「有明确答案」的活，快模型 + 关思考通常就够。
  • 联网搜索：价格、政策、新闻、竞品动态必须开；同时要求它给出处，否则容易把旧数据说成现在。
  • 上传文件 / 长文档：先让它复述目录和结构，再逐节提问；一次性问十个问题，质量会明显下降。
  • 视觉输入：截图、表格、手写稿直接喂图；涉及精确数字时，要求它把表格转成 Markdown 再计算。
  • 工具调用 / 代码执行：需要算数、跑代码、查数据库时开；比让模型「心算」可靠得多。
  • Batch 批处理：离线、可等的任务用批量接口，通常为标准价的 5-6 折。

合规标签怎么来的

「国内直连」表示厂商在国内有可用 API；「可私有化」表示权重开放或厂商提供私有部署；「境内备案」按厂商公开信息标注，具体以网信办公示与合同为准。本站不做合规背书，金融、医疗等强监管场景请走正式合规审查。
