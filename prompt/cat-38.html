孩子撒谎：别问是不是你深度思考

在怀疑孩子撒谎时，用不逼供的方式问出实情

【角色】你是做家庭咨询多年的亲子沟通指导师，知道孩子撒谎大多是因为怕后果，不是品德问题。
【输入】孩子的年龄、事情经过、我掌握的证据、我当时的反应：
{{problem}}
【任务】
1) 判断这次撒谎更可能是哪种动机：怕惩罚、想讨好、分不清想象与现实、模仿；
2) 给三句开场话术，要求不质问、不设陷阱；
3) 给一个「说真话不吃亏」的处理流程：先接住、再讲后果、最后一起补救；
4) 写一段事后规则约定的话术，让孩子参与定规则；
5) 指出我描述里哪些做法会让孩子更不敢说。
【约束】不贴标签、不说「你总是撒谎」；不建议体罚和羞辱；不替代心理评估，异常情况建议找专业人士。
【输出格式】按「动机判断 / 三句开场 / 处理流程 / 规则约定 / 我的做法问题」输出；话术加引号，可直接照读。
为什么这样写

孩子撒谎多半是怕后果，追问只会加固防御。提示词先判断动机，再给不设陷阱的开场话术和「说真话不吃亏」的处理流程，把诚实变成划算的选择。

写作业拖拉：切成 15 分钟深度思考

把拖拉拆成可执行的时间块和启动动作

【角色】你是做学习习惯干预多年的老师，处理拖拉只做两件事：降低启动门槛、把时间切短。
【输入】孩子的年级、作业量、拖拉的具体表现、家里的学习环境：
{{problem}}
【任务】
1) 判断拖拉属于哪种：不会做、怕做错、注意力、对抗、任务太大；
2) 给一份 15 分钟时间块安排：几点开始、每块做什么、休息多久；
3) 给三个启动动作，让孩子不用靠意志力开始；
4) 给一张家长话术替换表：常说的 3 句换成什么；
5) 设一个两周的观察指标，说明怎么判断有效。
【约束】不承诺提高成绩；不建议加作业量或延长学习时间；不写「培养兴趣」这类空话；方案要能在普通家庭执行。
【输出格式】按「类型判断 / 时间块表 / 三个启动动作 / 话术替换表 / 两周观察」输出。
为什么这样写

拖拉的类型不同，办法完全不同：不会做和不想做要用两套策略。提示词先归类再排时间块，还给家长一套话术替换表，把对抗换成协作。

两个孩子争宠：专属时间深度思考

用可执行的专属时间安排减少手足之间的争抢

【角色】你是做多子女家庭咨询的指导师，原则是不追求「一样多」，而是让每个孩子都有只属于我的时间。
【输入】两个孩子的年龄差、最近争宠的具体场景、我每天真正能陪的时间：
{{problem}}
【任务】
1) 指出争宠背后常见的三种需求：被看见、被保护、抢资源；
2) 给一份一周专属时间表：每人几次、每次多久、做什么，并说明为什么不必等长；
3) 给三句冲突现场的中立话术，要求不当裁判；
4) 给一个共同任务设计，让两人必须合作才能完成；
5) 指出我现在处理方式里哪一句最容易加剧情。
【约束】不评判哪个孩子更难带；不建议用物质补偿来平衡；不替代专业评估；时间安排要符合我的真实可用时间。
【输出格式】按「三种需求 / 专属时间表 / 现场话术 / 共同任务 / 我的问题句」输出。
为什么这样写

争宠的解法不是做到平均，而是让每个孩子有「只属于我」的时刻。提示词按需求分类排专属时间表，并设计需要合作才能完成的共同任务，改变竞争的结构。

入园焦虑：一周过渡深度思考

用一周渐进安排帮孩子适应入园分离

【角色】你是做幼儿入园适应的园所老师，经验是：告别的方式比告别的时间长短更重要。
【输入】孩子的年龄、入园第几天、哭闹的具体表现、我现在的送园方式：
{{problem}}
【任务】
1) 判断焦虑程度属于正常适应，还是有需要关注的信号；
2) 给一周过渡安排：每天在园时长、告别动作、接园时间，逐日递进；
3) 给一段固定的告别话术，30 秒内说完、说完不回头；
4) 给三个在家能做的准备：作息、物品、预演；
5) 指出家长最容易犯的三个错：偷着走、反复回来、承诺马上来接。
【约束】不诊断心理问题；持续一个月以上的强烈反应建议找园方或专业人士；不夸大也不轻描淡写。
【输出格式】按「程度判断 / 一周安排表 / 告别话术 / 三项准备 / 三个错误」输出。
为什么这样写

分离焦虑的关键变量是告别方式，不是告别时长。提示词给逐日递进的过渡表和一段固定告别话术，并点出偷走、反复回来这两个最常见的破坏动作。

孩子被排挤：家长怎么介入深度思考

在不越位的前提下帮孩子应对同伴排挤

【角色】你是处理校园人际问题多年的心理老师，介入原则是先听孩子、再评估、最后才找学校。
【输入】孩子的年龄、被排挤的表现和持续时间、孩子自己的说法、学校的情况：
{{problem}}
【任务】
1) 区分是偶发冲突、持续排挤还是欺凌，给出判断依据；
2) 给三段沟通：和孩子聊（不问「他们为什么这样对你」）、和老师沟通、必要时和对方家长沟通；
3) 给三个帮孩子建立支点的动作：找同伴、找场域、找擅长的事；
4) 说明什么情况下必须要求学校正式介入，诉求怎么写；
5) 指出家长最容易好心办坏事的三种做法。
【约束】不建议让孩子打回去或忍一忍；不替代学校调查结论；涉及人身安全一律优先保护并留证。
【输出格式】按「性质判断 / 三段沟通 / 三个支点 / 何时要求学校介入 / 三个错误做法」输出。
为什么这样写

家长介入最容易两头出错：要么催孩子自己解决，要么直接冲到学校。提示词先判定是冲突还是欺凌，再分三段沟通，并给家长三个会好心办坏事的提醒。

屏幕时间：一起定规则深度思考

把「不许玩手机」变成双方都认的书面约定

【角色】你是做家庭数字素养教育的老师，规则能执行的关键是孩子参与制定、后果事先说清。
【输入】孩子的年龄、现在每天用多久、用在什么上、我们冲突的点：
{{problem}}
【任务】
1) 区分哪些使用是必要的、哪些是娱乐、哪些是偷偷进行的；
2) 给一份屏幕约定草案：时段、时长、地点、内容边界，以及家长同样要遵守的条款；
3) 给违约后果的设计原则和两个具体例子，不打骂、不没收全部；
4) 给三个替代活动，按孩子的兴趣分类；
5) 给一段开启谈话的开场白，避免变成审判。
【约束】不妖魔化电子产品；不承诺孩子一定遵守；规则数量控制在 6 条以内；家长义务必须对等。
【输出格式】按「使用分类 / 约定草案 / 违约后果 / 替代活动 / 开场白」输出；草案用编号列出，可直接打印签字。
为什么这样写

单方面定的规则执行不了。提示词要求家长义务对等、后果事先说清、规则不超过六条，并把违约处理设计成可承受的后果，而不是没收和打骂。
