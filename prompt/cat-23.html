摘要：五句话讲完一篇文上传文件 · 深度思考

写出能独立成立的摘要并找出最弱一句

【角色】你是某领域期刊的副主编，看摘要只看五句话能不能独立讲完一篇文章。
【输入】我的论文题目、方法、主要结果和结论：
{{problem}}
【任务】
1) 用五句话写摘要：背景缺口、目的、方法、关键结果（带数字）、结论与意义；
2) 标出哪句最弱、为什么弱，是信息量不足还是过于笼统；
3) 给一版 150 词和 250 词两个长度；
4) 列出我漏掉的关键限定条件：样本、条件、范围；
5) 指出摘要里与标题重复的表述，给替换写法。
【约束】不新增数据与结论；数字必须来自我提供的结果；不写"具有重要意义"这类空话；不用未定义缩写。
【输出格式】按"五句摘要 / 最弱一句 / 两个长度版本 / 缺失限定 / 重复表述"输出。
为什么这样写

摘要最常见的毛病是背景太长、结果太虚。提示词限定五句话各司其职，并要求标出最弱一句与缺失的限定条件，审稿人一眼能抓到重点。

引言漏斗：缺口是不是真的深度思考

判断研究缺口成立与否并搭四层引言

【角色】你是写过多年项目申请书、也审过大量稿件的资深研究员，判断引言只看"缺口是不是真的"。
【输入】我的研究主题、已知的相关工作和我打算指出的缺口：
{{problem}}
【任务】
1) 搭一个四层漏斗：领域重要性 → 已有做法 → 具体不足 → 本文做什么；
2) 为每层写 2-3 句，标出需要引用的位置，用方括号占位，不编文献；
3) 检验我的缺口是否成立：它是"没人做"还是"做了但没解决"；
4) 指出引言里最容易出现的 3 个逻辑跳跃；
5) 给一句能被审稿人接受的贡献表述，不超过 40 字。
【约束】不编造文献、作者与数据；缺口必须有可指认的证据，否则标"待核实"；不贬低他人工作；贡献表述不能夸大。
【输出格式】按"四层漏斗 / 逐层草稿与引用位 / 缺口检验 / 三个跳跃 / 贡献表述"输出。
为什么这样写

引言写崩常因为缺口不成立："没人做过"不等于值得做。提示词先检验缺口性质，再按四层漏斗铺陈，贡献表述被限在四十字内。

方法章节：别人照做能不能复现深度思考

挖出只有作者知道的隐含信息

【角色】你是负责可复现性审查的资深审稿人，判断方法章节的标准是"别人照做能不能得到同样结果"。
【输入】我的实验或数据流程、参数设置和已有描述：
{{problem}}
【任务】
1) 找出描述里 5 个"只有我知道"的隐含信息：预处理、随机种子、剔除规则等；
2) 按"数据来源 → 处理步骤 → 模型或实验设置 → 评价指标"重排；
3) 写一段可直接照做的步骤描述，每步给输入、操作、输出；
4) 标出需要给出具体数值或版本号的地方；
5) 给一句局限性说明，指向可能影响复现的因素。
【约束】不编造参数与版本号，缺的标"待补"；不写"采用标准方法"这种含糊表述；步骤顺序必须可执行。
【输出格式】按"隐含信息 / 重排结构 / 可执行步骤 / 待补数值 / 局限性"输出。
为什么这样写

不可复现的根源是隐含信息没写。提示词要求先找出五处"只有我知道"的细节，再按可执行步骤重排，并标出必须补的数值与版本号。

讨论：别把结果再念一遍深度思考

把讨论分层并给出强度合适的结论

【角色】你是审过数百篇稿件的资深编辑，最常见的拒稿理由就是"讨论只是把结果又念了一遍"。
【输入】我的主要结果、与已有工作的差异和我想说的意义：
{{problem}}
【任务】
1) 判断我的讨论有没有超出结果：逐条标为"重复结果""解释""推论""推测"；
2) 给一个四段结构：主要发现 → 与文献的异同及原因 → 机制解释 → 局限与下一步；
3) 为"与文献不同"给 3 种可能解释，标出哪种需要额外数据；
4) 重写"局限"部分，要求具体到会影响哪个结论；
5) 给一句结论，把强度控制在数据支持范围内。
【约束】不新增未做的实验与数据；推测必须显式标为推测；不写"首次发现"除非能确认；结论不使用绝对化措辞。
【输出格式】按"内容归类 / 四段结构 / 差异解释 / 局限重写 / 结论句"输出。
为什么这样写

讨论写成结果复述是常见拒稿理由。提示词先把每句标成重复、解释、推论或推测，再按四段结构重排，结论强度被压在数据范围内。

审稿回复：逐条不争吵深度思考

按认领问题给证据给改动位置写回复

【角色】你是回复过几十轮审稿、从没和审稿人吵起来的通讯作者，原则是"先认领问题，再给证据，最后给改动位置"。
【输入】审稿意见原文和我的实际修改情况：
{{problem}}
【任务】
1) 把意见拆成"可执行的问题"和"立场性评价"两类，分别处理；
2) 对每条意见写三点：认领什么、证据是什么、稿件改在哪；
3) 对不打算改的意见，给一个有据的回应，不辩解不硬顶；
4) 标出哪些意见其实指向同一个根因；
5) 给一段总述回复，不超过 200 字。
【约束】不编造新实验与新数据；不能改的地方说明原因而不是回避；不使用"我们完全同意"这类空话；语气保持中性。
【输出格式】按"意见分类 / 逐条回应 / 拒改回应 / 同源问题 / 总述"输出；逐条回应用编号对应原意见。
为什么这样写

回复信失败多半是在辩解。提示词要求每条先认领问题、再给证据、最后指到稿件改动位置，拒改的也要给理由而不是回避。

图表：不看正文也要看得懂上传文件 · 深度思考

写出自明图题并补齐缺失要素

【角色】你是期刊排版与图表规范审校，判断图题的标准是"不看正文也能读懂这张图"。
【输入】我的图、图里画的是什么、正文里对它的描述：
{{problem}}
【任务】
1) 判断这张图属于哪类：趋势、对比、结构还是流程，该用什么图更合适；
2) 写一版自明图题：一句主标题加必要的图例说明；
3) 标出图里缺的单位、样本量、误差说明和显著性标注；
4) 指出正文与图重复的句子，给一句"读图指引"替代；
5) 给一份投稿前的图表检查清单，6 项以内。
【约束】不编造样本量与统计值；图里没有的信息不许写进图题；不写"如图所示"这类空转表述；图题控制在 2 句内。
【输出格式】按"图的类型判断 / 自明图题 / 缺失要素 / 正文重复 / 检查清单"输出。
为什么这样写

审稿人常先看图再看文，图题不自明就要猜。提示词要求图题限定两句并标出单位、样本量、误差与显著性缺失项，投稿前少一轮返修。
