评测方法与数据边界

这份页面回答一个问题：网页上的“场景匹配分”和价格，到底是怎么来的、能信到什么程度。它不是官方 benchmark，也不代表真实成功率。

1. 五层证据链

层我们记录什么当前状态
来源价格/能力数据对应的官网或公开页面37 个模型有官方同步；其余标注折算/推算
时间价格核验日、数据快照日价格同步日与数据快照日分开显示
样本评测任务数、运行次数、样本量当前没有公开评测样本，能力分为人工十维
方法维度、权重、评分规则自研十维，权重为站内人工设定
不确定性证据等级、未验证项、可能错在哪每个推荐分数可点开查看

2. 场景匹配分怎么算

分数由十维能力画像、任务拆解、硬约束过滤、预算/时间/token 约束共同决定。它不是模型“绝对强弱”，而是“这个任务下是否合适”。

  • 先过滤硬约束：私有化、图片、音频、视频、长上下文、零预算
  • 再按任务所需维度加权
  • 最后按预算、时间、token 余量做加减分
  • 输出 0-100 的匹配分，分数越高越适合当前任务
这不是成功率。没有在真实用户任务上跑过，不能承诺“用了就一定好”。

3. 证据等级 A / B / C

A官方价格 + 公开评测样本。当前没有模型达到 A。

B价格可追溯（官方/折算）+ 人工十维能力评估，没有公开评测样本。

C价格为推算/折算，能力为人工十维评估，只适合横向比较。

证据等级会显示在模型卡片、详情和推荐结果里。C 级模型不应该被当成“最优解”。

4. 价格口径

标签含义使用建议
官方价厂商官网/公开定价页，自动同步或人工核验可直接用于预算
折算价按汇率、套餐或阶梯价折算下单前以官方账单为准
推算价同级产品估算，不是厂商报价只做横向比较，不用于精确预算

每次打开模型库或模型详情，页面会请求本站最新的价格快照，并显示快照时间、核验时间和数据年龄。快照更新依赖同步任务，不是厂商实时报价。

5. 评测样本：当前为 0

我们不会把“人工十维”包装成 benchmark。当前公开评测样本为 0；下一步计划做最小评测：

  • 10 个模型 × 30 个任务
  • 每个任务运行 3 次
  • 人工 rubric + 自动格式检查
  • 公开任务样例、评分标准、失败案例和样本量

在样本量足够之前，页面只展示“场景匹配分”，不展示“能力排名”或“成功率”。

6. 榜单边界

  • 场景匹配榜：按任务类型和约束排序，是站内规则结果。
  • 能力参考榜：接入公开评测样本后才上线；当前不展示。
  • 不把用户本机评分混入公共榜单。

7. 反馈、纠错与版本

发现价格、上下文、模态或能力标注错误，请用页面右下角「反馈」选择「数据纠错」，附上来源链接。反馈会进入 Netlify Forms 后台，不进入模型厂商。
